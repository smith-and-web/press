Disclosures

Hairlines establish the rhythm. Native disclosure behavior keeps answers close without hiding the question.

Can I use these components without a framework?

Yes. Load the local fonts, tokens, and website stylesheet, then use the HTML markup. Add the optional script for interactive patterns.

Does this change the application’s design?

No. Website styles are opt-in and scoped. The canonical tokens and existing application examples remain available separately.

Where should I change a shared color?

Edit the canonical tokens.css file, regenerate the mirrors, and release a new package version. Do not maintain a second palette in a consumer.
